# Idea Refine

Turns vague ideas into concrete, actionable proposals.

## When To Use
- "I have an idea but I'm not sure how to approach it"
- Exploring multiple directions before committing
- Vague concepts that need shape before spec writing

## Process

### Phase 1 — Diverge (explore broadly)
Generate 3–5 distinct directions. For each:
- Core concept in one sentence
- Key assumption it rests on
- Biggest risk if that assumption is wrong

### Phase 2 — Evaluate
Score each direction:
- **Impact** (1–5): How much does this move the needle?
- **Feasibility** (1–5): How realistic given constraints?
- **Clarity** (1–5): How well-understood is the path?

### Phase 3 — Converge (select and sharpen)
Pick the highest-scoring direction. Then:
1. State the core insight in one sentence
2. Define the minimum version (MVP)
3. Define the full version
4. Identify the biggest unknown

### Phase 4 — Proposal

```markdown
## Idea: [Name]

### The Insight
[One sentence: the core idea]

### The Problem It Solves
[For whom, and why it matters]

### Minimum Version
[Smallest thing that validates the idea]

### Full Version
[What it becomes if the MVP succeeds]

### Biggest Unknown
[The assumption most likely to be wrong]

### Next Step
[ ] Write spec → spec-driven-development
[ ] Run more research → source-driven-development
[ ] Prototype first → incremental-implementation
```
